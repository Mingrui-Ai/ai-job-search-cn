## 决策

- 不改数据库/schema、RULES_VERSION、评分算法、权限或依赖；不读取真实 data，不联网收集数据。
- 不读当前 profile/job/match 或无关材料，不输出正文、备注/回复或联系方式；只公开虚构测试数据。
- 首次登记投出时快照不自动等于投出前判断；作废重投沿用旧快照、同日顺序未知、旧岗位摘要口径不同均单独标记，历史 profile 无法验证。
- 计数均可从 rows 复算，不估计成功率、不推断因果、不自动学习权重。复盘不自动重评旧岗位；用户确认具体权重后只按现有工作流改 weights/偏好记录。
