**决策**

- 草稿由命令写，不让 Agent 手抄：
  - 记录有两三百行，手抄容易改动规则部分，校验就会反复失败；
  - Windows PowerShell 5.1 的 `>` 会存成 UTF-16，`match validate` 只读 UTF-8。
- 总分由校验给出，Agent 只照抄：设计稿要求 Agent 不能改总分，但补了经历以后总分一定会变。让校验给出应填的值，篡改仍会被拒绝，Agent 也不用自己算。
- 工作流放在 `match.md` 开头：Agent 打开这份文件，先读到的就是要照做的步骤；规则、记录格式等参考内容放在后面。
- 走查里两份草稿的方向都是规则给的分数，"Agent 补方向"这一支没有走到。它的校验在 `test_cn_score.py` 里已经覆盖。
