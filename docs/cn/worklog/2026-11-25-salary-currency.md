# 2026-11-25 · 不把外币工资标成人民币

## 完成

`jd parse` 之前把“薪资：USD 20-30K/月”输出为 20000–30000 CNY/month。现在金额紧邻明确外币标记时留空，不自动换汇或套用人民币单位。

## 决策

继续使用现有仅支持 CNY 的 schema。币种判断仅匹配金额前后的币种、常见工资修饰语和括号；其他分句里的外币融资或结算职责不影响人民币工资。

## 验证

新增公开 CLI 测试覆盖前置代码、后置中文币种、括号、税前、符号、日薪和时薪，并验证无关外币叙述及后续人民币报价。原版出现 10 个失败子用例，修复后通过。技能检查、框架版本检查、仓库守卫及完整 unittest 均通过（2343 项，54 项按环境跳过）。

## 遗留

不新增币种 schema 或汇率转换；外币金额可根据原文后续人工处理。
