# 2026-11-18 · M6 远程岗位复审修复

## 完成

修复同一岗位换链接后重复入库，以及不同岗位使用相同文案时被合并。详情表头的公司名和职称完整入库，证据保留标点。补上本地过期判断和旧批次迁移。门户搜索分别记录无效行和有效结果，各种格式的详情均要求有正文。

## 决策

- 站点的 `pubDate` 表示最后更新时间。门户输出保留 `updated_at`，首次发布日期未知时 `date` 为 null，按发布日期限制的搜索会排除这些岗位。CN 初筛从正文取明确发布日期，未知日期按现有规则提示待确认。
- 来源 GUID 包含公司及岗位 slug。适配器将二者原样放在收件元数据中，并对组合标识取 SHA-256 写入 `site_job_id`。旧格式的官方申请链接可以还原该标识。重放旧收件时保留已有岗位编号、状态和首次导入时间。如果仅提供了比库内记录更早的收件，先跳过该旧格式岗位并提示重放最新原件。
- 来源提供明确到期时刻时，离线初筛从有效期截止时起计为已过期。当天对照实际时刻，指定其他参考日期时对照当地当日结束时刻。岗位可以提前下架，重新对外展示仍需详情核验。
- 一次指令最多请求一页。HTTP 限流、服务端异常和跳转结束本次访问。单条无效卡片可被单独跳过，有效详情与搜索结果仍保留来源链接。
