# 2026-11-18 · M6-3 北森门户搜索与详情入口

## 完成

- 为用户点名的租户和频道提供门户契约的搜索与详情命令。

## 决策

- 搜索仅打开一个城市的第一页。详情独立按需读取。两者沿用单文档的 robots、限速、禁止重定向与关闭时复查。
- 复用租户白名单与两代门户的解析器。默认通用搜索由技能的 enabled 开关跳过本门户。
- 新版响应的岗位 ID 只关联在响应与可见列表中都唯一的标题和编号。日期取明确的发布标签或表头。旧版规范链接的频道取显式参数或唯一的白名单频道。
- Bun 从技能所在仓库调用 Python，白名单的相对路径仍按调用者所在目录解释。搜索 JSON 在标准的 `commands/search.ts` 入口核对并输出六个字段。
