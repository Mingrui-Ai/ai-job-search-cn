## 决策

- 按官方发布 tag 解析提交，并读取该提交的 `action.yml` 核对运行时。现有 setup-bun 的固定提交已使用 Node.js 24。
- 官方要求 Actions Runner 至少 v2.327.1；本仓库使用 GitHub 托管 runner，验收覆盖 Linux、Windows，以及 texlive-latest 和 Debian bookworm 两种现有容器。
- checkout v7 对 `pull_request_target` 和 `workflow_run` 的 fork 检出增加默认限制；本仓库的 PR 检查使用 `pull_request`，保留新版默认保护。setup-python v7 移除的 `pip-install` 输入在本仓库没有使用。
- 本项属于现有 CI 维护；求职功能、工作流触发条件、权限、测试矩阵和 `persist-credentials: false` 约定不变。
