# 2026-11-18 · M6 远程实习岗位来源

## 完成

新增 Himalayas 门户 CLI。它使用同一官方公开 API 完成按居住国和岗位类型搜索、单个开放岗位核验和本地收件导出。CN 导入流程指向采集说明。实际走通了搜索、详情、格式检查、入库、评分和重复导入。

修复中文 JD 解析器对结构化收件中较长英文标题及明确标注的实习性质漏读的问题。较长的英文标题要求同一个抬头同时出现公司与工作性质，使用虚构的带逗号英文岗位名覆盖了这条路径。

## 决策

- 核对官方 API 文档、API 条款第 113 节和 robots。只查未分页搜索与详情接口。保留源站申请地址、标注来源，详情关闭时停止展示。依据见[来源参考](../../../.agents/skills/himalayas-search/url-reference.md)。
- 搜索返回的国家范围和时区作为来源元数据保存，城市、本地用工条件和报酬需由正文佐证。API 的岗位总数和本次实际检查数分别报告。
- 本地 CN 工作流直接调用新 CLI。上游通用抓取的默认搜索策略继续由用户配置。实现沿用现有 JSON 收件格式、URL 去重和本地存储约定。

## 验证

- 真实搜索返回结果，并通过三个单岗详情接口确认当时处于开放状态。三条均经过 `jd screen --check` 和正式筛选。英文标题和实习类型与来源字段一致。最终再导入，三条均为 unchanged。岗位原件、评分和短名单只保存在本机。
- 新 CLI 的类型检查、离线用例和显式启用的真实搜索用例通过。覆盖错误参数、到期时间、来源链接和文本清理。解析器回归模块 29 项通过。
- 首次全量检查发现搜索命令的文件位置不符合仓库的门户契约。按已有适配器结构拆分入口后，契约与解析回归 36 项通过。最终 Python 测试共发现 2327 项，按模块分四片，2283 项通过、44 项环境跳过、零失败。技能 lint、安全守卫及 diff 空白检查通过。
