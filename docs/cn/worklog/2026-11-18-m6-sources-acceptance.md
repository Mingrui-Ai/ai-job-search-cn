## 决策

M6-2 已有两个来源的核实记录。M6-3 还要求门户可经上游通用契约调用。以下对照针对本次核验的主干提交。[上游门户契约](../../../.claude/commands/add-portal.md)

| 契约项 | 北森 CN 入口的核对结果 |
| --- | --- |
| 技能发现、注册及测试 | 当前入口为 `python -m jobsearch_cn collect beisen`，没有可供 `/scrape` 发现的北森门户技能、Bun CLI 包或门户测试脚本。已有 Python 离线测试和真实采集记录。 |
| 搜索、详情、参数 | 支持白名单租户、频道、城市、关键词和单详情 URL。城市取自白名单，页数与详情数分别由 `--max-pages`、`--max` 限制。缺少通用 `search`、`detail <id或url>`、`-q`、`--jobage`、`--page`、`--limit`、`--location` 和 `--format` 接口。 |
| 输出和错误 | CN 返回运行摘要和独立收件文件。缺少通用的 `meta.count/page`、六项固定字段的 `results` 和三种格式。CN 有开始失败、访问停止、结构变化等多种退出码，与门户规定的 stderr 错误对象和退出码 1 有差异。 |
| 抓取、解析及文本 | CN 使用受限 Chrome、结构化响应或逐行解析的 DOM、可见字段提取和 JD 防注入检查。遇限停止。通用契约另有具名请求身份、退避、404 处理、单卡隔离和逐项清理不可见字符等要求，现有 CN 入口未通过该套门户验收。 |
| 依赖、凭据和来源标识 | 北森免凭据。CN 运行时依赖本机 Chrome 和可选 Playwright；通用 CLI 默认用 Bun。北森岗位 ID 已进入 Job Schema，支持跨批次去重。 |

Himalayas 已有通用搜索、详情和输出格式，可显式调用；默认多门户搜索中关闭。其分页和遇限处理按来源要求收紧。北森的 CN 成果和 Himalayas 的门户实现保留各自的适用范围。[Himalayas 门户说明](../../../.agents/skills/himalayas-search/SKILL.md)
