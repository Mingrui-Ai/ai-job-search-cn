## 决策

- 复用 collect 的节奏、上限、停止条件、断点续抓和原子写入；真实数据仅存指定的本机数据目录。
- 只操作专用 Chrome 中本次新开的标签，用完关闭。不读取 Cookie、请求头或留出样例，不修改安全守卫。
- 当前 master 禁止 `official` 来源顶层 `site_job_id`。为按要求用 master 出短名单，本实现使用 `site: official`、官网长数字 ID 原样放在 `extra.site_job_id` 和文件名，按完整官网 URL 去重；默认批次名前缀为 `bytedance-`，避免与其他官网批次混淆。已向规划者提出字段位置差异供裁定；本次未扩展 Schema、未冒用门户来源。
- 官网页面 DOM 已提供完整列表 / 详情，因此未读取 JSON 接口，也没有逆向或构造签名参数。
- 参数来自官网筛选操作后的地址：关键词 `keywords`、广州 `location=CT_45`、页码 `current`、每页 `limit=10`。仅内置现场确认的广州；其他城市通过 `--city-code` 给出官网代码。
- 正文保留岗位名、标签、职位描述、职位要求；没有的公司 / 薪资字段保持未知。官网“职位 ID”展示标签与详情 URL 中的长数字 ID 均保留，后者用于文件和 URL 续抓。

### robots.txt

2026-11-05，从本次新开的专用 Chrome 标签读取 `https://jobs.bytedance.com/robots.txt`：HTTP 200，无跳转。内容为：

```text
User-agent: *
Allow: /experienced
Allow: /society
Allow: /campus
Allow: /en
Allow: /jp
Disallow: /referral
```

本适配只接受 HTTPS 的 `jobs.bytedance.com/campus/position` 及其数字 ID 详情路径；排除 `/referral`、站外链接、非默认端口、带用户信息的链接。官网公开页面不要求登录；导航栏的“登录”链接不当作登录拦截。实际登录墙、验证码、HTTP 401/403/429、离开公开路径则停止。
