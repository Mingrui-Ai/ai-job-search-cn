# 2026-11-10 · M6-3 北森适配器首审修复

## 完成

- 修复 PR #149 首审的两个 P2（审核基线 `2fcb0cc`）。本轮仅使用手写虚构页面与接口响应，没有访问真实北森门户。
- 导航、频道切换和滚动前，浏览器先交付等待期间收到的响应，再用当前页面所属适配器检查新快照。只有检查通过才能清空旧页面响应并导航；403、429、5xx、业务失败和无法识别的响应都会停止租户，并在采集结果中说明原因。
- 新旧北森门户共用的主文档检查改为拒绝所有已知非 2xx 状态。列表和详情内容即使可识别，也不会进入岗位解析或保存；结果保留具体 HTTP 状态码。
- 新增 6 个离线测试方法：一个主文档状态矩阵、四个延迟错误场景，以及一个延迟正常响应的对照。错误出现在已存第一条详情之后时，停止后续导航并保留原件。

## 决策

- 页面响应是否失败仍由适配器判断；浏览器只负责交付响应与动作前检查，不主动构造、发送或重放接口请求。
- 动作前检查绑定的是当前已读页面的规则，避免切换频道或关键词时误用下一页的上下文。滚动快照原有的状态约定保持兼容。
- P3（标题数值薪资覆盖详情“面议”）按规划者裁定另派，本轮没有修改解析器。
