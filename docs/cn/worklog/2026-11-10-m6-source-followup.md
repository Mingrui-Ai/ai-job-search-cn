## 决策

- 来源核查只能证明已取得的官方链路、原文及停止状态；开源许可或平台市场页条款不能替代托管服务、租户的访问依据。
- 聚合 CLI 既有自动重试与本次遇限制即停的要求不同，未直接运行 live CLI，也未修改上游技能或权限。
- M6-1 第一版限既有北森白名单租户的严格单详情 URL；默认跳过已知岗位，显式重读保存新收件原件；不直接写岗位、档案或投递库。
- 单链接 robots 无跳转、无重试，获取失败或规则不可靠时停止；只使用临时隔离浏览器，在 document 跳转请求前阻止后跳。正常渲染资源与单次 document 预算分开记录，不宣传为零附加网络。
- 独立验证使用本机虚构 HTTP 服务和已有浏览器，验证目标端点请求计数；不以 mock 或最终 URL 检查代替前置停止证据。不安装软件、不连接用户浏览器、不实采真实来源。
