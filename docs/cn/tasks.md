- **负责人**：`用户` 做决定、合并、自用验收；`规划` 写任务单、审 PR、调整计划；`执行` 实现、测试、写工作记录。

- **粒度**：当前里程碑拆到每个 PR；后面的里程碑只列大项，开工前由规划者细化成任务单。
- 完成一项就勾掉，并写上 PR 号。
